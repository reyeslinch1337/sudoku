# Передача контекста: брейншторм Extreme Sudoku

Дата: 2026-10-09. Документ написан в локальной сессии Claude Code перед переходом в облачную сессию,
чтобы новая сессия продолжила работу без потери контекста. Переписка из локальной сессии в облако
не переносится, поэтому всё важное записано здесь.

## Цель

Пользователь хочет веб-судоку, в котором есть только задачи экстремальной сложности. Игра должна быть
доступна из интернета и удобна на iPhone.

## Процесс

Работа идёт по процессу brainstorming из плагина superpowers, путь "architectural" (новый проект).
Если плагина superpowers в облачной сессии нет, всё равно следовать этим шагам:

1. Исследовать контекст проекта. Сделано: папка была пустой.
2. Задать уточняющие вопросы по одному. Сделано, ответы ниже.
3. Предложить 2-3 подхода. Сделано, выбран подход A.
4. Сделано: показать дизайн по секциям и после каждой секции получить одобрение пользователя.
   Секции: архитектура и модули, движок решателя и рейтинг, генератор банка задач, UX подсказок,
   экран игры и ввод на iPhone, хранение состояния и статистика, PWA и деплой, тестирование.
5. Сделано: записать утверждённый дизайн в спек `docs/superpowers/specs/2026-10-09-extreme-sudoku-design.md` и закоммитить.
6. Сделано: провести самопроверку спека: нет плейсхолдеров, противоречий и двусмысленностей, объём укладывается в один план.
7. Сделано: попросить пользователя прочитать спек и дождаться одобрения.
8. **СЛЕДУЮЩИЙ ШАГ:** план написан (`docs/superpowers/plans/2026-10-09-extreme-sudoku-plan.md`), ждёт утверждения. Написать план реализации (skill superpowers:writing-plans), согласовать способ исполнения.
9. Только после этого писать код.

Жёсткое правило: код продукта не пишется, пока пользователь не утвердил спек и план.
Вопросы пользователю задавать по одному за раз, по возможности с вариантами ответа.

## Утверждённые решения

| Тема | Решение | Комментарий |
|---|---|---|
| Сложность | "Предел логики": задачи, которые человек решает чистой логикой без угадывания, примерно Sudoku Explainer 7.5-9.5 | Не "самые сложные в мире" (SE 10+), где без перебора не обойтись. Подуровней внутри экстрима нет. |
| Источник задач | Подход A: заранее сгенерированный банк из **500 задач** | См. раздел ниже |
| Хостинг | GitHub Pages, публичный репозиторий `reyeslinch1337/sudoku` | Итоговый адрес: `https://reyeslinch1337.github.io/sudoku/` |
| Функции сверх базы | Все четыре: авто-кандидаты, проверка ошибок, логические подсказки, таймер и статистика | |
| Язык | Переключатель RU/EN | Названия техник в обоих языках остаются общепринятыми английскими (X-Wing, XY-Chain) |
| Стек | TypeScript + Vite + Preact, тесты на Vitest | Пользователь не возражал против этого стека при выборе подхода A |
| Установка | PWA: manifest и service worker, установка на домашний экран, офлайн-режим | |
| Деплой | GitHub Actions собирает и публикует в Pages при push в main | |
| Хранение | localStorage на устройстве: текущая игра, статистика, язык | Аккаунтов и сервера нет |

Базовые функции, которые считаются обязательными (пользователь видел этот список и не возражал):
сетка, ввод цифр, режим пометок-кандидатов, undo, стирание, подсветка одинаковых цифр,
подсветка конфликтов, автосохранение текущей игры.

Принятые допущения: играет в основном сам пользователь, возможно друзья по ссылке. Аккаунты,
рейтинги и мультиплеер не нужны.

## Подход A подробно (выбран)

- Один решатель на TypeScript, имитирующий человека, используется в двух местах: в браузере для
  подсказок и в Node-скрипте для генерации и рейтинга задач.
- Node-скрипт офлайн генерирует задачи, прогоняет их через решатель и оставляет только те, которые
  требуют техник верхнего уровня (цепочки, ALS, forcing chains) **и** которые решатель доводит до конца.
- Результат: 500 задач в статическом JSON (около 100 КБ), он кладётся в сборку.
- При выдаче задача случайно трансформируется с сохранением логики: перестановка цифр, перестановки
  строк внутри полос и самих полос, то же для столбцов, транспонирование. Визуально задачи не повторяются.
- Главная гарантия: подсказки и отбор задач работают на одном движке, поэтому не бывает задачи,
  на которой подсказка не знает следующего шага.

Отвергнутые варианты:
- B, генерация на iPhone в Web Worker. Экстремальные задачи среди случайных редки, ожидание новой
  игры было бы непредсказуемым, от секунд до минут.
- C, готовые списки задач с форумов. Рейтинг там посчитан другим решателем, наш движок подсказок
  может не дорешать часть задач, лицензия неясна.

## Черновые идеи для секций дизайна (НЕ утверждены, вынести на обсуждение)

- Набор техник решателя по возрастанию сложности: naked/hidden single; pointing и claiming;
  naked/hidden pair, triple, quad; X-Wing, Swordfish, Jellyfish (возможно finned-варианты);
  XY-Wing, XYZ-Wing, W-Wing; Skyscraper, 2-String Kite (или общий X-Chain);
  Unique Rectangle типов 1, 2, 4 (решить, включать ли техники уникальности);
  XY-Chain, AIC; ALS-XZ, ALS-XY-Wing; cell forcing chains и digit forcing chains с ограниченной глубиной.
- Собственная шкала рейтинга, привязанная к самой сложной технике в решении, примерно
  в масштабе Sudoku Explainer. Порог попадания в банк определить в дизайне.
- Генератор: случайная полная сетка, удаление подсказок до минимальной задачи с единственным решением,
  рейтинг. Чтобы быстрее набрать сложные задачи, мутировать уже найденные сложные задачи
  (изменить несколько подсказок, снова минимизировать, оставить, если задача стала сложнее).
- UX подсказки в три нажатия: 1) название техники, 2) подсветка задействованных клеток,
  3) показать и применить вывод.
- Перед подсказкой проверять ошибки игрока: неверно поставленные цифры и удалённые верные кандидаты.
  Если ошибка есть, подсказка говорит об этом, а не строит логику на испорченном состоянии.
- "Эффективные кандидаты" для решателя: пометки игрока, если они есть в клетке, иначе все кандидаты,
  допустимые по уже поставленным цифрам.
- Проверка ошибок: сравнение с решением, отдельно для цифр и для кандидатов.
- Таймер останавливается, когда приложение уходит в фон (visibilitychange). Статистика: число решённых
  задач, лучшее и среднее время, использованные подсказки и проверки.
- Новая игра выдаёт случайную ещё не решённую задачу из банка. Рейтинг задачи показывать числом,
  без названия самой сложной техники, чтобы не было спойлера.
- iPhone: сетка на всю ширину, цифровая панель 1-9, переключатель цифра/пометка, стирание, undo/redo,
  учёт safe-area, запрет масштабирования двойным тапом, meta-теги для режима standalone, иконки.
- Тема светлая/тёмная по системной настройке.
- Язык по умолчанию определять по `navigator.language`, выбор хранить в localStorage.
