## Этап C. Код устройства и доставка сообщений

Ветка `device-messages`. Выпускается вместе с расширением банка (или сразу после него).

- [ ] Код устройства: генерация, хранение в настройках, строка и кнопка "Скопировать" в настройках.
- [ ] `src/app/messages.ts`: шифрование и расшифровка (WebCrypto), разбор файла сообщений.
- [ ] Доставка: запрос при запуске и возвращении из фона, локальная копия, правила показа (4).
- [ ] Показ через карточку поздравления.
- [ ] `scripts/message.ts` и команда `npm run message` (add, remove); пустой `public/messages.json`.
- [ ] Исключить `messages.json` из предкэша service worker.
- [ ] Тесты по спеку 6; `CLAUDE.md`: как отправить сообщение.

Готово, когда: CI зелёный, код устройства виден в настройках на сайте.
