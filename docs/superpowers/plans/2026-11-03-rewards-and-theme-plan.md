## Этап E. Звезда, корона, тёмный бордовый

Ветка `rewards`, начинается от `theme-burgundy` с влитым `main`.

- [ ] Общий компонент вылета конфетти (из карточки поздравления), палитра задаётся параметром.
- [ ] Экран победы: золотая звезда, "Успех!", золотые конфетти.
- [ ] Короны: хранение `xsudoku.v1.crowns`, проверка пройденного уровня при победе, карточка короны,
      значок в окне выбора уровня; экспорт и импорт.
- [ ] Тёмная тема: бордовые токены.
- [ ] Тесты по спеку 4.
- [ ] Скриншоты: экран победы, карточка короны, окно выбора уровня с короной, игра в тёмной теме.

Порядок выпуска: PR открывается, но вливается только после того, как пользователь одобрит скриншоты.
