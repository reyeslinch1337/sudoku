# Расширение банка и поздравление по ссылке: план

Основан на спеке [2026-11-03-bank-expansion-and-greeting-design.md](../specs/2026-11-03-bank-expansion-and-greeting-design.md).
Порядок исполнения прежний: этап в своей ветке, PR в `main`, слияние при зелёном CI.

## Этап A. Поздравление по ссылке

Ветка `greeting`. Не зависит от генерации, поэтому идёт первым.

- [ ] `src/app/greeting.ts`: кодирование и раскодирование base64url UTF-8, лимит длины.
- [ ] `scripts/greeting-link.ts` и команда `npm run greeting-link`.
- [ ] Компонент карточки с SVG-сердечками, анимация конфетти и сердечек, учёт reduced motion.
- [ ] Чтение параметра при старте, очистка адреса после показа.
- [ ] Тесты: кодек, компонент, e2e.

Готово, когда: CI зелёный, ссылка для пользователя собрана.

## Этап B. Расширение банка

Ветка `bank/expand`. После окончания генерации уровня 9.

- [ ] `LEVEL_QUOTA = 367`; режим дополнения в `import-collections` (`--base`, `--add`), равномерный отбор уровня 9.
- [ ] Новый `src/data/puzzles.json`: прежние 501 задача плюс по 200 на уровень.
- [ ] Тесты режима дополнения и банка; `verify-bank`.
- [ ] `CLAUDE.md`: как дополнять банк.

Готово, когда: `verify-bank` проходит, CI зелёный, все прежние задачи на месте.
