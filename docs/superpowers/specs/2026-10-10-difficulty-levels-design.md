# Уровни сложности 9 / 10 / 11+: дизайн

Дата: 2026-10-10. Статус: утверждён пользователем по итогам обсуждения.
Дополняет и частично заменяет основной спек [2026-10-09-extreme-sudoku-design.md](2026-10-09-extreme-sudoku-design.md).
Где документы расходятся, действует этот.

## 1. Что меняется и почему

Пользователь хочет порог жёстче и задачи уровней 10 и 11+ по шкале Sudoku Explainer (SE). Решения:

- рейтинги 7.x и 8.x из банка убираются, банк состоит только из задач 9+;
- задачи 10 и 11+ берутся из публичных коллекций сложнейших задач, а не генерируются;
- уровень задачи определяется по источнику;
- там, где наш решатель не находит логического шага, подсказок нет;
- при новой игре игрок выбирает уровень.

Это пересматривает исходное решение "не самые сложные в мире": задачи 10 и 11+ требуют вложенных
допущений и нашим решателем не решаются.

## 2. Банк

### 2.1 Состав

| Уровень | Источник                                    | Количество | Числовой рейтинг |
| ------- | ------------------------------------------- | ---------- | ---------------- |
| 9       | наш генератор, рейтинг 9.0-9.5              | 167        | есть             |
| 10      | ph_1905 без задач из списка 11+             | 167        | нет              |
| 11+     | список 11+ (ph_1905, рейтинг SE не ниже 11) | 167        | нет              |

Если какой-то уровень не наберётся полностью, банк собирается из того, что есть; меньше 501 задачи допустимо.

### 2.2 Источник коллекций

Набор данных проекта tdoku (`data.zip` в репозитории `t-dillon/tdoku`, лицензия BSD-2):
`puzzles4_forum_hardest_1905` (около 2.1 млн задач) и `puzzles5_forum_hardest_1905_11+` (48 766 задач).
Это выгрузки из темы "The hardest sudokus" форума enjoysudoku.com. Рейтингов в файлах нет.

Файлы коллекций в репозиторий не попадают. Попадают только отобранные задачи в `src/data/puzzles.json`
и файл `src/data/NOTICE.md` с указанием источника. Тот же текст показывается в настройках игры.

### 2.3 Отбор задач коллекций

Скрипт `scripts/import-collections.ts`:

1. читает оба файла (путь к `data.zip` или к распакованной папке передаётся аргументом);
2. для уровня 10 берёт задачи ph_1905, которых нет в списке 11+; для уровня 11+ берёт список 11+;
3. перемешивает кандидатов детерминированным ГПСЧ с заданным seed;
4. принимает задачу, если у неё ровно одно решение, её отпечаток не встречается в банке
   (включая уровень 9) и наш решатель её не решает;
5. останавливается, набрав квоту уровня.

Минимальность для уровней 10 и 11+ не требуется: задачи берутся как есть.

### 2.4 Формат

```json
[
  { "p": "...", "l": 9, "r": 9.1 },
  { "p": "...", "l": 10 },
  { "p": "...", "l": 11 }
]
```

`l` — уровень (9, 10 или 11; 11 означает "11+"). `r` есть только у уровня 9.

### 2.5 Генератор

Квоты 7.x и 8.x удаляются, остаётся одна: 167 задач с рейтингом 9.0-9.5. Минимальный рейтинг
генератора становится 9.0. Остальное (быстрый фильтр, мутации, ограничение рода) без изменений.

### 2.6 Проверка банка

`npm run verify-bank`:

- уровень 9: как раньше (единственность, решаемость, совпадение рейтинга, минимальность);
- уровни 10 и 11+: единственность решения и то, что наш решатель задачу не решает;
- для всего банка: формат, нет дубликатов по отпечатку, в каждом уровне не больше 167 задач.

## 3. Игра

### 3.1 Выбор уровня

"Новая игра" открывает окно с тремя кнопками: "9", "10", "11+". Под каждой подпись и прогресс:

- 9: "Подсказки работают", "решено N из M";
- 10 и 11+: "Без подсказок", "решено N из M".

M — число задач уровня в банке. Последний выбранный уровень хранится в настройках и подсвечивается.
Если текущая партия не закончена, перед окном выбора спрашивается подтверждение, как сейчас.
Новая задача выбирается случайно среди нерешённых задач уровня; когда решены все, среди всех задач уровня.

При первом запуске (сохранённой партии нет) игра начинается на уровне 9 без окна выбора.

### 3.2 Отображение

В шапке: числовой рейтинг для уровня 9 ("9.1"), "10" или "11+" для остальных.
Партии из старого банка (рейтинг 7.x или 8.x) показывают свой рейтинг как раньше.

### 3.3 Подсказки

Порядок прежний: сначала ошибки игрока, затем логический шаг. Если шаг не найден, подсказка
показывает "Для этой задачи логическая подсказка недоступна" и не засчитывается в статистику.
Проверка ошибок работает на всех уровнях.

### 3.4 Статистика

В запись о решении добавляется уровень. Разбивка 7.x / 8.x / 9.x заменяется на 9 / 10 / 11+.
Записи без уровня (решения задач старого банка) учитываются только в разделе "Все".
Прогресс по банку считается по каждому уровню.

### 3.5 Совместимость

- Сохранённая партия хранит ссылку на задачу (строку и трансформацию) и продолжает работать,
  даже если задачи больше нет в банке.
- В `PuzzleRef` добавляется необязательное поле `level`. Его отсутствие означает партию старого банка.
- Настройки получают поле `level` (по умолчанию 9). Формат ключей `xsudoku.v1.*` не меняется.

## 4. Тесты

- генератор: квота одного уровня 9.x;
- импорт: детерминированность, отбор по правилам 2.3, исключение задач, решаемых нашим движком;
- банк: уровни, квоты, дубликаты; выборочная полная проверка уровня 9;
- выбор задачи по уровню;
- подсказка на задаче уровня 11+: шаг не найден, счётчик подсказок не растёт;
- статистика по уровням, записи без уровня;
- интерфейс: окно выбора уровня, отображение уровня в шапке;
- e2e: новая игра с выбором уровня 11+.
