# Расширение банка и поздравление по ссылке: дизайн

Дата: 2026-11-03. Статус: утверждён пользователем по итогам обсуждения.
Дополняет спек уровней [2026-10-10-difficulty-levels-design.md](2026-10-10-difficulty-levels-design.md).

## 1. Расширение банка

### 1.1 Цель

Добавить по 200 задач в каждый уровень: квота уровня становится 367 вместо 167.
Прогресс игроков должен сохраниться.

### 1.2 Сохранность данных игроков

Данные игроков хранятся только на их устройствах (localStorage). Статистика ссылается на строку
задачи, текущая партия хранит свою задачу целиком. Поэтому:

- все 501 текущие задачи остаются в банке без изменений, новые только добавляются;
- решённые задачи остаются решёнными, меняется только знаменатель прогресса;
- формат банка и ключи хранилища не меняются.

### 1.3 Новые задачи

- Уровни 10 и 11+: по 200 задач из тех же коллекций tdoku по тем же правилам отбора
  (одно решение, нет дубликата по отпечатку среди всего банка, наш решатель не решает), seed 2.
- Уровень 9: 200 задач из продолженной генерации (seed 1), которых нет в банке по отпечатку.
  Отбор равномерный по рейтингу: уровни рейтинга 9.0, 9.1, ... берут задачи по очереди.

### 1.4 Сборка

`scripts/import-collections.ts` получает режим дополнения: `--base FILE` (текущий банк) и
`--add N` (сколько задач добавить в каждый уровень). В этом режиме он сохраняет базу целиком и
дописывает задачи. `LEVEL_QUOTA` становится 367. `verify-bank` проверяет весь банк.

## 2. Поздравление по ссылке

### 2.1 Ссылка

`https://reyeslinch1337.github.io/sudoku/?g=<данные>`, где данные — base64url от UTF-8 текста.
Текст в коде и репозитории не хранится. Ссылку собирает `npm run greeting-link -- "текст"`.
Строки текста разделяются символом перевода строки.

### 2.2 Показ

- При загрузке страницы с параметром `g` поверх игры открывается карточка: нарисованные (SVG)
  сердечки и текст, каждая строка отдельным абзацем, кнопка "Спасибо" ("Thank you").
- При открытии из центра вылетают конфетти и вверх всплывают сердечки, около 4 секунд.
- При `prefers-reduced-motion: reduce` анимации нет, карточка показывается сразу.
- После показа параметр удаляется из адреса (`history.replaceState`): обновление страницы
  поздравление не повторяет, новое открытие ссылки показывает его снова.
- Эмодзи не используются (правило проекта): сердечки и конфетти рисуются графикой.

### 2.3 Надёжность и безопасность

- Текст выводится как текст, не как HTML. Длина ограничена 500 символами.
- Битый или пустой параметр игнорируется, игра открывается как обычно.
- Работает офлайн, если игра уже загружалась на устройстве (service worker отдаёт страницу
  для адреса с параметром).
- На iPhone ссылка открывается в Safari, у которого свои данные, отдельные от приложения
  на экране Домой; на прогресс в приложении это не влияет.

## 3. Тесты

- банк: все прежние задачи на месте, уровни по 367, `verify-bank`;
- импорт в режиме дополнения: база сохраняется, нет дубликатов, равномерный отбор уровня 9;
- ссылка: кодирование и раскодирование кириллицы и переводов строк, битые данные, лимит длины;
- интерфейс: карточка появляется по параметру и закрывается, без параметра её нет;
- e2e: открытие ссылки показывает карточку, после закрытия игра работает и адрес очищен.
